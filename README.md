# 소방청 화재발생 통계 분석 (2020–2024)

전국 254개 시군구의 5년치 화재 데이터를 인구 데이터와 결합해, 지역 간 화재 발생 격차의 구조를 통계적으로 분석한 프로젝트입니다. **Python과 SAS 두 언어로 동일 분석을 병행**하여 모든 결과를 교차검증했습니다.

## 분석 개요

| 항목 | 내용 |
|---|---|
| 데이터 | 소방청 화재발생 정보 (2020.01.01–2024.12.31, 191,509건)<br>행정안전부 주민등록인구 월간 통계 (60개월) |
| 분석 단위 | 254개 시군구 (시도+시군구 조합) |
| 도구 | Python (pandas, statsmodels, scipy), SAS (PROC GENMOD, NPAR1WAY, FREQ) |
| 최종 모델 | 음이항 회귀 (인구 로그 오프셋) |

## 분석 파이프라인

```
1단계 전처리   원자료 정제 → 시군구 집계 → 인구 데이터 병합 → 파생변수
2단계 EDA      탐색 → 1차 변수선택 → 파생변수 → 2차 변수선택(VIF) → 최종 변수선택
3단계 통계검정  정규성 → Mann-Whitney U → Kruskal-Wallis → 카이제곱 → 과산포
4단계 모델링   포아송 → 과산포 진단 → 음이항 → 잔차 진단 → 누락변수 보정
5단계 인사이트  AS-IS 현황 → 우선순위 지역 → 원인별 개입지점 → TO-BE 제언
```

## 주요 결과

### 1. 화재 발생율은 도시성에 따라 단계적으로 증가

<img width="1050" height="750" alt="01_fire_rate_by_region" src="https://github.com/user-attachments/assets/6521966f-2260-4deb-b4d4-cdbe42bda896" />

화재 원인·장소·계절 구성을 모두 통제한 뒤의 인구당 발생율비입니다.

| 지역유형 | 지역 수 | 발생율비 (구 기준) |
|---|---|---|
| 구(區) | 104 | 1.00 |
| 시(市) | 67 | 1.41배 |
| 군(郡) | 83 | 2.61배 |

초기에는 군 vs 시·구 이분법으로 접근해 군지역 2.13배라는 결과를 얻었으나, **잔차 진단에서 도농복합시(공주시·상주시·문경시 등)가 체계적으로 과소예측**되는 것을 발견하고 3분류로 재설정했습니다. 재적합 결과 세 그룹의 잔차 편향이 모두 해소되었고 (구 +0.002 / 군 +0.003 / 시 +0.002), AIC 3,459.6 → 3,426.9, Pearson χ²/DF 1.0355 → 1.0024로 개선되었습니다.

### 2. 같은 '부주의'라도 지역별 내용이 다르다

전체 화재의 47.4%가 부주의 원인이며, 세부 내용은 지역유형에 따라 뚜렷하게 갈립니다.

### 3. 농촌은 "더 치명적인 화재"가 아니라 "더 자주 나는 화재"

화재 1,000건당 사망자는 군 8.01명, 시·구 8.27명으로 차이가 작습니다. 개입 방향은 사후 대응 강화보다 발생 자체를 줄이는 예방이 우선입니다.

## 기술적 학습 포인트

- **오프셋(offset)을 활용한 카운트 회귀**: 인구 규모가 다른 지역의 화재건수를 비교하기 위해 로그 인구를 오프셋으로 투입
- **과산포 진단과 모델 선택**: 포아송 Deviance/DF = 125.16 → 음이항 1.06으로 개선, AIC 33,403 → 3,635. 최종 3분류 모델에서는 Pearson χ²/DF = 1.0024로 이상값(1.0)에 근접
- **잔차 진단을 통한 모델 재설정**: 전체 잔차 평균(0.004)은 양호했으나 그룹별로 쪼개자 체계적 편향(군 +0.975 / 시·구 −0.467)이 드러남
- **누락변수 편의 관찰**: 동절기화재비율 계수가 모델 개선에 따라 5.945 → 2.721 → 1.808로 감소, 초기 모델에서 농촌 효과를 대신 흡수하고 있었음을 확인
- **효과크기 해석 단위 검토**: 비율변수의 "10%p 변화" 해석이 표준편차 대비 비현실적 외삽(3.49 SD)이 되는 경우를 확인하고 1SD 기준으로 재계산
- **Python ↔ SAS 교차검증**: 전 단계 결과를 소수점 4자리 이상 일치 확인. statsmodels 수렴 경고 발생 시 SAS 결과로 타당성 확인

## 데이터 정제 과정에서 처리한 이슈

- 행정구역 개편(2023.6 강원특별자치도, 2024.1 전북특별자치도)으로 인구 데이터 행이 분리된 문제 → 신 명칭 기준 합산
- 군위군의 2023.7 경상북도 → 대구광역시 편입 → 실제 관할 이동이므로 분리 유지
- 시 하위 자치구 표기 불일치("용인시처인구" vs "청주시 흥덕구") → 공백 제거 표준화
- 세종특별자치시는 하위 시군구가 없어 시도 총계행을 시군구 단위로 사용
- `PROC IMPORT`의 `guessingrows` 미지정으로 한글 컬럼값이 잘려 조인이 조용히 실패한 문제 → `guessingrows=max` 적용
- CSV 저장 시 `utf-8` → `utf-8-sig`로 변경하여 한글 인코딩 깨짐 해결

## 분석의 한계

- 본 분석은 **관측된 연관성**을 보여줄 뿐 인과관계를 입증하지 않습니다.
- Pseudo R² 0.102로, 모델이 설명하는 부분은 지역 간 차이의 일부입니다.
- 산업구조, 건축물 노후도, 소방서 접근시간, 고령화율 등 주요 변수가 포함되지 않았습니다.
- 최종 모델에서도 |잔차| > 3인 3개 지역(포천시·종로구·공주시)의 고유 요인은 설명되지 않았습니다.
- 시도별 잔차에 공간적 자기상관 가능성이 남아 있으나, 지리 인접정보 부재로 다루지 못했습니다.
- 지역 분류를 시군구 명칭의 끝글자로 판정했으므로, 명칭과 실제 도농 특성이 어긋나는 사례가 있을 수 있습니다.
