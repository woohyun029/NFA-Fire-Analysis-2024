### 📅 26.07.24 | Phase 1: SAS 데이터 전처리 및 로직 검증

#### 1. 주요 작업 내용
* 전일(07.23) Python으로 완료한 데이터 정제 및 병합 로직을 SAS 환경에서 동일하게 구현
* 데이터 소스 간 결합 및 집계 정합성 교차 검증 중

#### 2. 이슈 해결 로그 (Troubleshooting)
* **현상:** `PROC IMPORT`를 이용한 데이터 로드 중, 특정 컬럼의 텍스트가 잘리거나 일부 값이 결측치(Missing)로 처리되는 현상 발생
* **원인:** SAS가 기본적으로 상위 일부 행만 스캔하여 변수 길이를 결정하기 때문에, 하단의 긴 텍스트를 수용하지 못함
* **해결:** `guessingrows=max;` 옵션을 추가하여 전체 데이터를 스캔하도록 설정, 데이터 유실 문제 해결

**📌 결과:** Python, SAS 1단계(전처리 및 파생변수 생성) 완료
