* **해결:** `guessingrows=max;` 옵션을 추가하여 전체 데이터를 스캔하도록 설정, 데이터 유실 문제 해결

### 📅 26.07.25 ~ 26.07.29 | Phase 2: 탐색적 데이터 분석(EDA) 및 파생변수 생성

#### 1. 주요 작업 내용
* **기초 통계 및 분포 확인**:
    - 왜도(Skewness) 측정을 통해 재산피해액과 사망자 수 데이터의 극심한 치우침 확인
    - 인구 대비 화재율(`FIRE_RATE_100K`) 계산 시 분포가 정규분포에 가깝게 안정화됨을 검증
* **이상치(Outlier) 탐색**:
    - IQR(Interquartile Range) 기준으로 화재 건수 및 피해액 상위 지역 식별
    - 경기 화성시, 경남 김해시 등 인구 밀집 지역의 화재 건수 이상치는 '규모 효과'로 해석
* **상관관계 분석 (Spearman)**:
    - 데이터의 비정규성을 고려하여 순위 기반의 스피어먼 상관계수 활용
    - 인구수와 화재 발생 건수 간의 강한 양의 상관관계(0.77) 확인 → 향후 분석 시 인구를 오프셋(Offset)으로 설정할 근거 마련
* **파생변수 생성**:
    - 원천 데이터를 시군구 단위로 재집계하여 3종 파생변수 생성: `부주의화재비율`, `주거시설화재비율`, `동절기화재비율`

#### 2. 데이터 분석 인사이트 (EDA Interpretation)
* **피해액 데이터의 특이성**: 재산피해액 이상치(이천시 등)는 지역의 취약성보다 '대형 물류센터 화재'와 같은 단일 사건의 영향이 지배적임을 파악
* **변수 역할 확립**: 인명 피해 및 재산 피해 변수는 화재의 '원인'이 아닌 '결과'이므로, 화재 발생 건수 예측 모델에서는 독립변수에서 제외하기로 결정
* **모델 적합성 판단**: 화재 발생 건수가 카운트 데이터이고 인구수와 비례하므로, 일반 회귀보다는 포아송(Poisson) 또는 음이항(Negative Binomial) 회귀 모델이 적합함을 도출

#### 3. 이슈 해결 및 환경 통합
* **데이터 포터블 확보**: Python에서 가공한 파생변수를 SAS에서 즉시 활용할 수 있도록 컬럼명 영문 표준화 및 `utf-8-sig` 인코딩 저장
* **결측치 검증**: 데이터 병합(Merge) 후 발생할 수 있는 결측치를 전수 점검하여 데이터 손실률 0% 확인

**📌 결과:** EDA를 통한 가설 설정 및 통계 모델링을 위한 최종 분석 데이터셋(`fire_clean_for_sas.csv`) 구축 완료
